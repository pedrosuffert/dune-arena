# Provenance

This `testbed/` directory is a vendored, runnable copy of the **DUNE-bmv2**
software-switch testbed, adapted for use in this project.

## Upstream source

- Repository: https://github.com/nds-group/DUNE-bmv2
- Commit: `566feed5c985a2d737d898c79b9fbb3e8b8cce92` (`566feed`, 2026-04-10,
  "fix: add bibtex to README.md")

The upstream project ships no standalone LICENSE file; attribution is via the
INFOCOM 2025 paper citation kept in `README.md` (BibTeX key `11044678`). That
citation block is preserved here. If you use this testbed in research, cite the
upstream paper as indicated in `README.md`.

## What was vendored

The upstream tree was copied as-is, minus build artifacts, experiment outputs,
and version-control metadata. The following were intentionally excluded so this
copy stays lean and runnable:

- `.git/`, `.gitignore` (no nested VCS)
- `__pycache__/`, `*.pyc`
- `p4objects/`, `logs/`, `pcaps/`, `merged_pcaps/`, `utils/experiment_pcaps/`
  (regenerated by `make build` / experiment runs)
- `*.pcap`, scratch `*.bak` / `*.prev` / `*.prev2` / `*.stub*` / `*.rawip.bak`
- `experiment_*.tar.gz`, `experiments.db`, `rf_run*.log`, `results_*.txt`,
  `recover_csv.py` (one-off experiment scratch)

Kept: `Makefile`, the P4 sources (`p4sources/`, `p4include/`), the Mininet
topology code (`dune/`), the table/converter and controller tooling
(`convert_RF_and_populate_tables.py`, `controller.py`,
`populate_forwarding_tables.py`, `upload_p4prog_to_switch.py`,
`evaluate_fattrees.py`), `utils/` (incl. `calculate_score.py`,
`prepare_pcap_traces.py`), `configs/`, `dune.lua`, `docs/`, `README.md`, the
small per-cluster sub-model files under `models/` (~9.6 MB, all `.sav`/`.json`),
and the input flow-count CSV in `data/`.

## Local adaptations applied on top of `566feed`

These uncommitted working-tree changes from the source checkout are included in
this vendored copy. From `git diff --stat` against `566feed`:

```
 convert_RF_and_populate_tables.py | 65 ++++++++++++++++++++++-----------
 dune/custom_topo.py               |  2 +-
 utils/calculate_score.py          |  4 +--
 utils/prepare_pcap_traces.py      | 75 ++++++++++++++++++++++++++-------------
 4 files changed, 97 insertions(+), 49 deletions(-)
```

Summary of the changes:

- **`convert_RF_and_populate_tables.py`** — generalized the voting-table
  populator from a hardcoded 3-class assumption to an arbitrary number of
  classes; added zero-split / full-range don't-care handling in the converter so
  degenerate tree splits map to full-range ternary entries.
- **`utils/prepare_pcap_traces.py`** — removed the stale `dos` entry from
  `eliminated_classes`; batched the tshark flow filter into chunks to stay under
  the shell `argv` length limit on large captures.
- **`utils/calculate_score.py`** — Python 3.12 / pandas 2 compatibility fixes.
  Note: the `classes = [...]` order near the top is rewritten per model by
  `treeshap/deploy_stage6.py` (global class-id order follows each model's
  Stage-5 sequence).
- **`dune/custom_topo.py`** — Python 3.12 / pandas 2 compatibility fix.

Applied later in this fork (2026-07-01):

- **`dune/custom_topo.py`** — `build()` now plumbs the `test_pcap` /
  `test_pcap_dir` topology arguments into topo attributes. Upstream never set
  them, so `--test=tonlinear` always replayed the default
  `./data/ToN_IoT_test.pcap` path regardless of the Makefile's `TEST_PCAP`
  variable (unnoticed upstream because the pcap sat at the default path).
- **`runlin.sh`** (new) — one-command line-topology run
  (`runlin.sh <model> <pps>`): mininet cleanup, p4 env, `make run-linear-test`
  with the repo's dataset paths, results scored.
